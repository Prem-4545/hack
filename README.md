# hack

Short description: A simple Python web app.

## How to run locally

1. Create and activate a virtual environment:

   python -m venv .venv
   .\.venv\Scripts\Activate.ps1

2. Install dependencies:

   python -m pip install -r requirements.txt

3. Run the app:

   python app.py
